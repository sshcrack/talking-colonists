# Getting Started

MineColonies Talking Citizens adds AI-powered voice chat to your MineColonies colony. Install the required mods, get a Gemini API key, and start talking to citizens within minutes.

!!! tip "TL;DR"
 Install mods → get API key → talk to citizen. The whole process takes about 5 minutes.
